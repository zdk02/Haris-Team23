READ THIS BEFORE QUOTING THE TABLE
  * Arm B has no name detection: Presidio is Haris's own detector, so lending
    it to the baseline would make the comparison circular. Arm B therefore
    cannot see a bare personal name. This limitation favours Haris — say so.
  * Arm B inspects egress messages only. Scanning internal hops as well would
    flag the legitimate source read in every scenario; egress-only is the
    charitable reading and the one a real DLP deployment uses.
  * Arm C never reads content and was not tuned against this corpus.
  * Wherever arm C matches or beats Haris, the thesis is unproven ON THIS
    CORPUS. That is a statement about the corpus, and it is what task K exists
    to fix — not a number to quietly drop from the report.
